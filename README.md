# BPMN Process Modeling Assignment

## Overview

This repository contains BPMN process models for business process scenarios created using Camunda Modeler.

Each exercise is maintained in a **separate GitHub branch** to keep the work organized and independent:

* **`ex-1`** — Exercise 1
* **`ex-2`** — Exercise 2

The assignment demonstrates the use of basic BPMN building blocks such as:

* Start Events
* Tasks
* Exclusive Gateways
* Sequence Flows
* Alternative Process Paths
* End Events

Each exercise can be accessed through its respective branch.
